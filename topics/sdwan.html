What is SD-WAN?

Cisco SD-WAN is a software-defined WAN solution that separates control-plane decisions from packet forwarding. It provides centralized management, secure overlay tunnels, application-aware routing, segmentation and policy control.

  • Centralized management through vManage.
  • Secure control-plane orchestration through vBond and vSmart.
  • Encrypted data-plane tunnels between WAN edge devices.
  • Application-aware path selection using loss, latency and jitter.

Cisco SD-WAN Controllers

vManage

Provides centralized configuration, monitoring, alarms, dashboards, APIs and software lifecycle management.

vBond

Authenticates devices, performs orchestration and helps WAN edge devices discover the required controllers.

vSmart

Acts as the centralized control-plane controller and exchanges routes, TLOCs, policies and security information using OMP.

WAN Edge

Forwards user traffic, forms secure tunnels and applies centralized or localized policies.

Control Connections

Cisco SD-WAN devices use secure DTLS or TLS control connections. A WAN edge normally connects first to vBond, then establishes permanent control connections to vSmart and vManage.

TLOC and OMP

A TLOC identifies a WAN transport endpoint using system IP, transport color and encapsulation. OMP distributes routes, TLOCs, services and policy information between WAN edge devices through vSmart.

Segmentation

Cisco SD-WAN uses VPNs to separate traffic. VPN 0 is the transport VPN, VPN 512 is the management VPN, and service VPNs carry user traffic.

  • VPN 0: underlay transport connectivity.
  • VPN 512: out-of-band management.
  • Service VPNs: enterprise applications and user segments.

Centralized and Localized Policies

Centralized policies are configured in vManage and enforced through vSmart. Localized policies are applied directly on WAN edge devices.

  • Control policy: influences OMP route exchange.
  • Data policy: controls traffic forwarding and service chaining.
  • Application-aware routing policy: selects paths using SLA metrics.
  • Localized policy: applies ACL, QoS and route policy locally.

SD-WAN Troubleshooting

  1. Verify underlay reachability and default routes.
  2. Check system IP, organization name and certificates.
  3. Validate vBond, vSmart and vManage control connections.
  4. Check OMP peers, routes and TLOC advertisements.
  5. Verify BFD sessions and tunnel health.
  6. Review policy, NAT, firewall and transport-port behavior.
