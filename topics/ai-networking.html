AI in Networking

AI can accelerate repetitive engineering tasks, but network engineers must validate every generated command, script and conclusion before using it in a real environment.

  • Generate draft automation scripts.
  • Explain protocols and logs.
  • Create test scenarios from requirements.
  • Summarize incidents and troubleshooting notes.
  • Search internal technical documents using RAG.

Prompt Engineering

A strong prompt clearly defines the role, goal, input, constraints and expected output.

Act as a senior network automation engineer.

            Goal:
            Validate that every WAN edge has active control connections.

            Input:
            A pyATS testbed and CLI output from show control connections.

            Constraints:
            - Do not hard-code device names.
            - Report failed devices clearly.
            - Do not change device configuration.

            Output:
            Provide executable Python code and a brief explanation.

AI-Assisted Code Generation

Use AI to create a first draft, then review it for correctness, security and scalability.

  1. Describe the topology and expected behavior.
  2. Provide realistic sample input.
  3. Define error-handling expectations.
  4. Ask for modular code.
  5. Test generated code in a lab before production use.

Requirement-to-Test Design

AI can convert a PRD into a structured test plan when the requirements are explicit.

  • Map every requirement to one or more testcases.
  • Include positive, negative and resiliency scenarios.
  • Define preconditions, steps and expected results.
  • Identify automation candidates.
  • Review for missing coverage and unsupported assumptions.

AI-Assisted Troubleshooting

Provide symptoms, scope, recent changes, topology and evidence instead of asking a vague question.

Symptom:
            Branch router cannot establish a control connection to vSmart.

            Evidence:
            - Underlay ping succeeds.
            - vBond connection is active.
            - Certificate is valid.
            - show control connections shows no vSmart peer.

            Task:
            Give a prioritized troubleshooting flow with verification commands.
            Do not recommend configuration changes until checks are completed.

Retrieval-Augmented Generation

RAG allows an AI application to retrieve relevant content from your documents before generating an answer.

  1. Extract text from documents.
  2. Split text into smaller chunks.
  3. Create embeddings.
  4. Store embeddings in a vector database.
  5. Retrieve relevant chunks for each question.
  6. Ask the LLM to answer only from retrieved evidence.

Responsible AI Use

  • Never expose passwords, API keys or confidential data.
  • Do not execute unknown commands directly on production devices.
  • Validate generated code with tests and code review.
  • Clearly separate sample output from real evidence.
  • Keep human approval for high-impact configuration changes.
