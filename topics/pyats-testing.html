What is pyATS?

pyATS is a Python-based test automation framework commonly used for network validation. Genie provides parsers, models and reusable network testing capabilities.

  • Structured setup, test and cleanup sections.
  • Device connectivity through testbed definitions.
  • Detailed logs and test result reporting.
  • Reusable parsers and network data models.

Testbed YAML

A testbed file stores device connection information separately from test logic.

testbed:
              name: peernet-lab

            devices:
              R1:
                os: iosxe
                type: router
                connections:
                  cli:
                    protocol: ssh
                    ip: 192.0.2.10
                credentials:
                  default:
                    username: admin
                    password: password

AEtest Structure

from pyats import aetest

            class CommonSetup(aetest.CommonSetup):

                @aetest.subsection
                def connect(self, testbed):
                    testbed.connect()


            class InterfaceValidation(aetest.Testcase):

                @aetest.test
                def verify_interfaces(self, testbed):
                    output = testbed.devices["R1"].parse(
                        "show ip interface brief"
                    )
                    self.passed("Interface output collected")


            class CommonCleanup(aetest.CommonCleanup):

                @aetest.subsection
                def disconnect(self, testbed):
                    testbed.disconnect()

Using Test Steps

Steps divide a testcase into clear actions and make failures easier to identify.

@aetest.test
            def validate_routing(self, steps, device):
                with steps.start("Collect routing table"):
                    routes = device.parse("show ip route")

                with steps.start("Validate default route"):
                    if "0.0.0.0/0" not in str(routes):
                        self.failed("Default route is missing")

Genie Parsing

Genie parsers convert CLI output into structured dictionaries.

interfaces = device.parse("show interfaces")

            for name, details in interfaces.items():
                operational = details.get("oper_status")
                print(name, operational)

Regression Testing

  1. Prepare a stable baseline build.
  2. Execute the same suite against the new build.
  3. Compare pass, fail, blocked and skipped results.
  4. Investigate new failures and environmental issues.
  5. File defects with logs, topology and reproduction steps.

Best Practices

  • Keep test data separate from test logic.
  • Use CommonSetup for discovery and connectivity.
  • Use CommonCleanup to restore changed state.
  • Write independent and repeatable testcases.
  • Validate actual device output rather than hard-coded success.
  • Record meaningful logs for failure analysis.
