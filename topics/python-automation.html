Python Basics

Python is widely used in network automation because it is readable, portable and supported by many networking libraries.

device_name = "R1"
            management_ip = "192.0.2.10"
            is_online = True

            print(f"{device_name}: {management_ip}, online={is_online}")

Functions

Functions make automation code reusable and easier to test.

def is_interface_up(status: str) -> bool:
                return status.strip().lower() == "up"

            print(is_interface_up("up"))

Lists and Dictionaries

Lists store ordered values, while dictionaries store key-value information.

devices = ["R1", "R2", "SW1"]

            interfaces = {
                "Gi0/0": "up",
                "Gi0/1": "down",
            }

            for interface, status in interfaces.items():
                print(interface, status)

Regular Expressions

Regular expressions are useful for extracting structured values from CLI output.

import re

            output = "Device ID: R1, IP: 192.0.2.10"
            match = re.search(r"IP:\s+(\d+\.\d+\.\d+\.\d+)", output)

            if match:
                print(match.group(1))

REST API Automation

REST APIs allow scripts to retrieve or modify controller and device data using HTTP methods.

import requests

            url = "https://api.example.com/devices"
            headers = {"Authorization": "Bearer TOKEN"}

            response = requests.get(url, headers=headers, timeout=30)
            response.raise_for_status()

            devices = response.json()
            print(devices)

SSH Automation

SSH automation can execute show commands on devices that do not provide a suitable API.

from netmiko import ConnectHandler

            device = {
                "device_type": "cisco_ios",
                "host": "192.0.2.10",
                "username": "admin",
                "password": "password",
            }

            connection = ConnectHandler(**device)
            output = connection.send_command("show ip interface brief")
            connection.disconnect()

            print(output)

Validation and Error Handling

Automation should validate real output and report clear failures instead of assuming success.

def validate_interfaces(interfaces: dict[str, str]) -> list[str]:
                failed = []

                for name, status in interfaces.items():
                    if status.lower() != "up":
                        failed.append(name)

                return failed

            failed_interfaces = validate_interfaces({
                "Gi0/0": "up",
                "Gi0/1": "down",
            })

            print("Failed:", failed_interfaces)
