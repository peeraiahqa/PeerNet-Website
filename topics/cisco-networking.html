Network Basics

A computer network connects devices so they can exchange data and share services.

Main network devices

  • Router: Connects different networks.
  • Switch: Connects devices inside a LAN.
  • Firewall: Controls and protects traffic.
  • Access Point: Provides wireless connectivity.

VLANs

A VLAN logically separates devices into different broadcast domains, even when they use the same physical switch. 

Switch(config)# vlan 10
Switch(config-vlan)# name USERS

Switch(config)# interface gi0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10

Spanning Tree Protocol

STP prevents Layer 2 loops by selecting a root bridge and placing redundant switch ports into a blocking state. 

show spanning-tree
show spanning-tree vlan 10
show interfaces status

OSPF

OSPF is a link-state routing protocol that calculates the best path using cost. 

router ospf 1
 network 10.0.0.0 0.0.0.255 area 0

show ip ospf neighbor
show ip route ospf

BGP

BGP is commonly used to exchange routes between autonomous systems and large enterprise networks. 

router bgp 65001
 neighbor 192.0.2.2 remote-as 65002

show ip bgp summary
show ip bgp

Troubleshooting Approach

  1. Check physical connectivity.
  2. Verify interface status.
  3. Validate IP configuration.
  4. Check VLAN and routing tables.
  5. Test connectivity using ping and traceroute.
