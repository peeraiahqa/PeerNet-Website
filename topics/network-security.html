Security Fundamentals

Network security protects confidentiality, integrity and availability while controlling who can access systems and data.

  • Confidentiality: prevent unauthorized disclosure.
  • Integrity: prevent unauthorized modification.
  • Availability: keep services reachable and reliable.
  • Authentication: verify identity.
  • Authorization: define permitted actions.

Firewalls and ACLs

Firewalls enforce traffic policy, while ACLs permit or deny traffic based on defined conditions.

ip access-list extended WEB-ACCESS
             permit tcp 10.10.10.0 0.0.0.255 host 192.0.2.20 eq 443
             deny ip any any log

            interface GigabitEthernet0/0
             ip access-group WEB-ACCESS in

IDS and IPS

An IDS detects suspicious activity and generates alerts. An IPS sits inline and can block or modify malicious traffic.

  • IDS: passive detection and alerting.
  • IPS: inline prevention and blocking.
  • Signature-based detection: matches known attack patterns.
  • Anomaly-based detection: identifies unusual behavior.

VPN and IPsec

IPsec protects traffic using encryption, authentication and integrity checks.

  • IKE negotiates security parameters and keys.
  • ESP provides encryption and integrity.
  • Site-to-site VPN connects networks.
  • Remote-access VPN connects individual users.
show crypto ikev2 sa
            show crypto ipsec sa
            show crypto session

TLS and HTTPS

HTTPS uses TLS to protect HTTP traffic. TLS validates server identity using certificates and creates encrypted session keys.

  1. Client initiates a TLS handshake.
  2. Server presents its certificate.
  3. Client validates the certificate chain.
  4. Both sides derive session keys.
  5. Application data is encrypted.

Snort

Snort is an open-source IDS/IPS that inspects packets and applies detection rules.

alert tcp any any -> 192.0.2.20 80 (
              msg:"Possible web scan";
              flags:S;
              threshold:type both, track by_src, count 20, seconds 10;
              sid:1000001;
              rev:1;
            )

Security Troubleshooting

  1. Identify the source, destination, protocol and port.
  2. Check routing before checking policy.
  3. Validate firewall zones and rule order.
  4. Review NAT translations and session tables.
  5. Check certificate validity and time synchronization.
  6. Use packet captures to confirm where traffic is dropped.
