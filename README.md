# PeerNet Solutions Website

A responsive static website for the PeerNet Solutions networking and automation YouTube channel.

## Open locally

Double-click `index.html`, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Free deployment options

- GitHub Pages
- Netlify
- Cloudflare Pages
- Vercel

## Customize

Update the YouTube link and email address in `index.html` before publishing.
